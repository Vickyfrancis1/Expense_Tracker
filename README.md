# Expense Tracker

A command-line expense tracker written in Python. Record what you spend, see totals per category, and keep your data between runs.

## Features

- Add expenses with a description, amount and category
- Totals grouped by category
- Data saved to a JSON file, so it is remembered next time
- Unit tests for the totals logic

## How to run

1. Install Python 3
2. Download `expense_tracker.py`.
3. Open a terminal in the same folder and run:

```
python expense_tracker.py
```

## How to run the tests

```
python expense_tracker_test.py
```

You should see `OK` at the end.
